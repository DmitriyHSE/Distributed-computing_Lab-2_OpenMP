# Задача 3. Стационарная температура пластины

Программа решает задачу Дирихле на квадратной сетке блочным методом Гаусса–Зейделя. OpenMP распределяет блоки одной диагонали между потоками.

## Windows · PowerShell

Понадобится GCC с поддержкой OpenMP, например MinGW-w64 из MSYS2. Команда `gcc --version` должна работать в PowerShell. Из корня репозитория выполните

```powershell
cd task_3_dirichlet
gcc -std=c11 -O2 -fopenmp dirichlet.c -o dirichlet.exe -lm
$env:OMP_NUM_THREADS = "4"
.\dirichlet.exe 65 8 1e-10 20 > temperature.txt
```

## Linux · Bash

Понадобится GCC с поддержкой OpenMP. В Ubuntu и Debian его можно установить командой `sudo apt install gcc`. Из корня репозитория выполните

```bash
cd task_3_dirichlet
gcc -std=c11 -O2 -fopenmp dirichlet.c -o dirichlet -lm
OMP_NUM_THREADS=4 ./dirichlet 65 8 1e-10 20 > temperature.txt
```

## Параметры и результат

Аргументы передаются по порядку.

| Аргумент | В примере | Значение |
|---|---|---|
| Число узлов по стороне | `65` | Включает обе границы, минимум 3 |
| Сторона блока | `8` | Число внутренних узлов вдоль стороны блока |
| Порог остановки | `1e-10` | Итерации заканчиваются, когда максимальное изменение температуры за проход не превышает порог |
| Температура границы | `20` | Одинакова на всех четырёх сторонах, по умолчанию 0 |
| Предел итераций | пропущен | По умолчанию 100000. При исчерпании лимита до сходимости программа сообщает об ошибке |

В примере файл `temperature.txt` содержит матрицу 65 × 65. Для быстрой проверки посмотрите на края матрицы (везде 20) и на центральный узел (около 20,0625). В терминале выводятся число проходов `sweeps`, последнее максимальное изменение `max_change` и время решения в секундах `solve_seconds`.

## Бенчмарк

Windows, Intel Core i5 11 поколения, GCC 14.2.0 с `-O2 -fopenmp`. Блок 16 × 16, порог `1e-8`, температура границы 20. Время — медиана трёх запусков до сходимости, без вывода матрицы. Ускорение считается относительно одного потока на той же сетке.

| Сетка | Потоки | Время, с | Ускорение | Эффективность |
|---|---:|---:|---:|---:|
| 65 × 65 | 1 | 0,058 | 1,00× | 100 % |
| 65 × 65 | 2 | 0,427 | 0,14× | 6,8 % |
| 65 × 65 | 4 | 0,751 | 0,08× | 1,9 % |
| 129 × 129 | 1 | 0,655 | 1,00× | 100 % |
| 129 × 129 | 2 | 3,097 | 0,21× | 10,6 % |
| 129 × 129 | 4 | 5,033 | 0,13× | 3,3 % |

На обеих сетках быстрее один поток. На коротких диагоналях мало независимых блоков, а между диагоналями потоки синхронизируются. Матрицы и число итераций совпали при всех трёх настройках. [Все 18 замеров](benchmark.json) · [Карта температур и график ускорения](demo.png)

Чтобы повторить бенчмарк, после сборки выполните в папке задачи

```shell
python -m pip install numpy matplotlib
python demo.py
```

В Linux при необходимости замените `python` на `python3`. Скрипт проверит результат по точному решению и обновит `benchmark.json` и `demo.png`.
